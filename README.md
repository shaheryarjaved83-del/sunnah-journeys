# Sunnah Journeys

A premium Umrah travel agency website built with Next.js 16, React 19, and Tailwind CSS v4.

## Features

- Responsive marketing site with animated hero, package catalog, and about pages
- Enquiry form with server-side validation (react-hook-form + Zod)
- Contact page with form, contact info, and FAQ
- Islamic design system: Cormorant Garamond serif, Amiri Arabic, emerald & gold palette
- SEO optimized with sitemap, robots.txt, and OpenGraph metadata
- Built with motion (framer-motion), GSAP, and Base UI components

## Tech Stack

- **Framework:** Next.js 16 (App Router, Turbopack)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4 (CSS-first config)
- **UI Components:** shadcn (base-nova style), Base UI
- **Animations:** Motion, GSAP
- **Forms:** React Hook Form + Zod
- **Package Manager:** npm

## Getting Started

```bash
npm install --legacy-peer-deps
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
npm start
```

## Project Structure

```
app/            # Next.js App Router pages
components/     # React components (layout, shared, home, about, packages, contact)
lib/            # Site config, package data, enquiry schema, utils
public/         # Static assets (images, patterns, icons)
```
